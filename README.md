# 6 Axis Robotic Arm

A multipurpose internet-controlled 6-axis robotic arm built using ESP32 and PCA9685 servo control.

## Features

- 6-axis articulated robotic arm
- Remote control over Wi-Fi
- ESP32 based control system
- Servo control using PCA9685
- Record and playback movements
- Expandable modular design

## Components

- ESP32
- PCA9685
- Servo motors
- Power supply
- Bearings
- Structural frame

## Project Goals

This project aims to create a low-cost robotic arm platform for learning robotics, automation, and remote control systems.
