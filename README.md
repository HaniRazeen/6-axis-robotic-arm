# 6 Axis Robotic Arm

A multipurpose internet-controlled 6-axis robotic arm using ESP32 and PCA9685 servo control.

## Project Overview

This project aims to build a low-cost robotic arm capable of remote operation through Wi-Fi. The robotic arm is designed for learning robotics, automation, object manipulation, and embedded systems.

## Planned Features

- 6-axis articulated movement
- Wi-Fi based remote control
- ESP32 control system
- PCA9685 servo management
- Movement recording and playback
- Modular and expandable structure

## Current Status

Currently in planning and early development stage.

## Main Components

- ESP32
- PCA9685
- Servo motors
- Bearings
- Structural frame
- External power supply

## Goals

- Learn robotics and automation
- Improve embedded programming skills
- Build a scalable robotic platform
- Create a web-based control interface
